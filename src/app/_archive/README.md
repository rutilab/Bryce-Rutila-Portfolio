# Archive

Pages retired from the live site, kept here so they aren't lost.

Folders whose names start with `_` are private in the Next.js app router: nothing
in here is routed, so none of it can be reached on the site. To bring a page back,
move it back under `src/app/` (and remove its redirect in `next.config.ts`).

- `projects/` — the Projects page (`/case-studies`) and the three folders it
  opened: Finding Focus, Personal Projects and Lastinger Center. Retired when the
  home page's Selected work took over as the way into the case studies. Each old
  address redirects to the home page.
